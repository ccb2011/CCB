# CCB v38

Стартовый путь: «приветствие → регистрация → выбор роли». Таймер перехода запускается до подготовки остальных разделов интерфейса, чтобы регистрация открылась даже при ошибке отрисовки дела.

В сцене оставлена стоящая Фемида: лицо без глаз и рта, повязка поднята выше, крылья и меч выполнены проще и спокойнее.

Четыре исходных аудиофайла сохранены. «Release — Ural Mountains» остаётся в пакете, но не показывается в списке настроек.

Знак CCB увеличен внутри иконок 192 и 512 px. Кнопка «Играть одному» запускается через отдельный приоритетный обработчик; при ошибке она остаётся доступной для повторного нажатия.

Кнопка одиночной игры теперь вызывает запуск напрямую, а экран входа скрывается сразу. Если обновление отдельных сведений завершится ошибкой, игровая страница всё равно открывается.

В библиотеке 80 современных тем и по 20 дел в каждой: всего 1600 дел. Сюжеты доступны на русском и казахском языках.

Логотип в левом верхнем углу использует прозрачный файл без отдельной подложки. Настройки оформлены компактными тёмными группами с тонкими границами и спокойным золотым акцентом.

Предыдущий каталог и архивное учебное дело заменены новым набором из 80 тем. Библиотека тем и дел остаётся доступной на вкладке «Дело» во время заседания. Кнопки смены роли открывают выбор роли напрямую, без окна подтверждения.


В v38 на экран «Дело» возвращена анимированная тематическая иллюстрация из прежней версии. Переключатель языка убран из верхней панели рядом с «Дело»; язык по-прежнему выбирается в настройках.
